# DARTS Engine (Dynamic Augmented Ragdoll Training Sandbox)

Welcome to the official repository for the **DARTS Engine**—a specialized 3D simulation sandbox designed for training embodied, physics-driven AI companions and stream agents.

---

## 📌 Overview

The DARTS Engine provides a dynamic, semi-realistic or toon-shaded 3D environment where artificial intelligence agents inhabit fully dynamic ragdoll bodies. Developers can interactively train their AI models in real time using PC or VR inputs, teaching them spatial awareness, motor balancing, and physical depth perception.

### Key Features
* **Stereoscopic Depth Perception:** Dual-camera visual pipelines (one camera per eye) simulating natural binocular vision for AI models.
* **Interactive Physics Training:** Dynamic ragdoll body framework adaptable via real-time user inputs (mouse/keyboard or VR controllers).
* **Embodied Agent Integration:** Purpose-built for streaming VTuber agents, interactive virtual companions, and autonomous broadcast personas.
